# Theme UI

Give your main menu a brand new look with multiple styles.

## Styles

- **Blocky**: a Minecraft-inspired menu with a slowly scrolling blocky world (sky, clouds, mountains, hills and trees), a stone-style logo, block buttons and a pulsing splash text.
- **Dark**: a clean dark gradient background.
- **Neon**: a purple and blue gradient with cyan buttons.
- **Default**: the normal Geometry Dash menu.

## How to use

1. Open the Geode menu, then **Mods**, then **Theme UI**, then **Settings**.
2. Pick a style.
3. Go back to the main menu to see the change.

## Notes

- Everything in the Blocky style is drawn in code, except the logo image.
- This mod only changes the main menu. Your music and gameplay stay untouched.
- This is a fan-made, unofficial theme and is not affiliated with Mojang or Microsoft.
